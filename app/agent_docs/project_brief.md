# Project Brief

## Product

- One-line vision: Helps consumers discover open class action settlements they qualify for and pre-fills the official claim form for them to review and submit themselves.
- Target users: Individual consumers checking eligibility for class action settlement payouts.
- Primary user outcome: Go from "is there money owed to me?" to a filled-in claim they can submit on the official settlement site, in one sitting.

## Scope

- Must ship:
  - Curated settlement list with eligibility questionnaire and disqualification gate.
  - Auto-fill claim preview (read-only, links to the official site).
  - Persistent non-legal-advice disclaimer.
- Not in v1:
  - Auto-submission / acting as the user's legal agent.
  - Accounts, saved profiles, notifications.
  - Automated settlement discovery (scraping).

## Principles

- Solve the user story before adding polish.
- Prefer boring, maintainable choices.
- Keep generated docs short and current.
- Verify user-visible work in the real product surface.
- The user always submits their own claim — this app never does it for them.
